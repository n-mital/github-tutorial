my project is about remote sensing in the skeena region for insect disturbances.
currently the bc government runs aerial overhead surveys using fixed-wing aircrafts to map pest disturbances.
due to logistical issues, not all of skeena region can be surveyed. 
the project aims to use remote sensing to address this gap in data.
remote sensing imagery will be processed and disturbances will be identified, both present and historical.
